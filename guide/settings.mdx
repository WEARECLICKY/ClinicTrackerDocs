## Overview

The Settings page is the control centre for your clinic's configuration.

## Organisation branding

Upload clinic logo, set brand tagline and primary colour, add social media links.

## Opening hours

Set operating days and times for each day. Multiple time ranges per day supported.

## Payment providers

Configure Stripe (publishable key, secret key, test/live mode) and BNPL providers (Klarna, Clearpay).

## Accounting integrations

Connect to Xero or QuickBooks Online to sync payments and invoices.

## Booking API

Generate and manage API keys for external booking systems.

## Messaging configuration

Set from email address, SMS from number, SMS sender ID. Verify email domain for reliable delivery.

## No-show and cancellation policy

Configure late cancellation fees, no-show fees, deposits, and first offence warnings.
