## Overview

The Adverse Events page documents any adverse reactions or complications that occur during or after a treatment.

## Event types

Bruising, Swelling, Infection, Allergic Reaction, Nerve Damage, Vascular Compromise, Scarring, Hyperpigmentation, Hypopigmentation, Nodule, Product Migration, Other.

## Severity levels

Mild (amber), Moderate (orange), Severe (red), Life Threatening (dark red).

## Recording a new event

1. Click **Record Event**
2. Select the client, event type, and severity
3. Enter the event date and description
4. Link to a treatment session if applicable
5. Set the resolution status (Ongoing, Resolved, Referred, Hospitalised)

<Warning>All adverse events should be documented promptly and accurately.</Warning>
