## Overview

The Prescriptions page manages the full POM workflow from request through prescriber approval to pharmacy transmission.

## Prescription statuses

| Status | Colour | Meaning |
|--------|--------|---------|
| Requested | Amber | A practitioner has requested a POM |
| Sent to Prescriber | Blue | Sent to the prescriber for approval |
| Signed by Prescriber | Indigo | Prescriber has digitally signed |
| Approved | Green | Approved and ready to action |
| Declined | Red | Prescriber has declined |
| Actioned | Teal | Treatment has been administered |
| Transmitted to Pharmacy | Teal | Sent to a pharmacy |

## Creating a prescription request

1. Click **New Prescription**
2. Select the client and treatment
3. Enter prescription details (medication, dosage, product)
4. Select the prescriber
5. Confirm face-to-face assessment
6. Set an expiry date
7. Click **Submit**

<Warning>POM prescriptions must only be approved by qualified prescribers.</Warning>
