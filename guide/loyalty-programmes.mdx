## Overview

The Loyalty Programmes page lets you create loyalty deals that reward clients for repeat visits.

## Creating a loyalty deal

1. Click **Create Deal**
2. Enter name and description
3. Choose reward type (Discount Percentage, Fixed Amount, or Free Treatment)
4. Set reward value and qualifying visits needed
5. Set start and end dates
6. Toggle Active
7. Click **Save**

## Enrolling clients

From the client's detail page, go to the Loyalty & Gifts tab, click **Enrol**, and select the deal.

<Tip>Offer a double-sided reward to encourage more referrals.</Tip>
