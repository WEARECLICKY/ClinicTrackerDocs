## Overview

The Automations page lets you create automated message workflows that trigger based on specific events.

## Automation triggers

| Trigger | Description |
|---------|-------------|
| Birthday | Sends on the client's birthday |
| Treatment Anniversary | Sends on the anniversary of a treatment |
| Post-Treatment | Sends a follow-up after a treatment |
| Recall Reminder | Sends when a treatment is due |
| New Client Welcome | Sends to new clients |
| Inactive Client Reactivation | Reaches out to inactive clients |
| Custom | A custom trigger |

## Creating an automation

1. Click **Create Automation**
2. Enter name and choose trigger
3. Select channel (Email, SMS, WhatsApp)
4. Enter subject and message body
5. Set the delay (days after trigger)
6. Toggle Active
7. Click **Save**

<Tip>Start with one or two automations and monitor their effectiveness.</Tip>
