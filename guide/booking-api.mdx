## Overview

ClinicTracker provides a secure API that lets external booking systems create bookings directly in your calendar.

## API key management

Generate API keys in Settings under the Booking API section. Each key is stored as a SHA-256 hash for security.

<Warning>Copy and save your API key immediately after generation. It is shown only once.</Warning>

## API actions

- **config** — returns available treatments and clinic details
- **slots** — returns available time slots for a given date and treatment
- **book** — creates the appointment, matches or creates the client, generates an invoice
- **balances** — returns gift card balances and loyalty enrolments

<Tip>Generate a separate API key for each external system.</Tip>
