## Overview

The Client Balances page tracks credit on client accounts for pre-payments, refunds, and future purchases.

## Topping up credit

Find the client, click **Top Up**, enter amount and description.

## Deducting credit

Find the client, click **Deduct**, enter amount, select type (Usage, Refund, Adjustment, Transfer).

## Transaction types

| Type | Colour | Description |
|------|--------|-------------|
| Top Up | Green | Credit added |
| Usage | Amber | Credit used |
| Refund | Blue | Credit returned |
| Adjustment | Grey | Manual correction |
| Transfer | Teal | Credit moved |

<Tip>Encourage clients to pre-pay for packages by offering a small discount.</Tip>
