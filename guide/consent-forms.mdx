## Overview

ClinicTracker includes a digital consent system with a pre-built library of forms for common aesthetic treatments.

## Smart matching

The system automatically suggests the best consent form based on the treatment name using keyword matching.

## Interactive signing

Consent forms render as interactive documents with checkboxes, text inputs, date pickers, and signature pads. Both client and practitioner can sign on-screen.

## Status tracking

Each form is tracked as Pending, Signed, or Declined. The Dashboard shows alerts for pending forms.

<Tip>Always review AI-generated consent forms carefully before use.</Tip>
