## Overview

The Photo Library is your central hub for client photos, showing all photos across all clients organised by date with type labels (Before, After, or Progress).

## Uploading photos

1. Click **Upload Photo**
2. Select the client and photo type
3. Add optional tags
4. Select the image file
5. Click **Upload**

Photos can also be uploaded directly from the Treatment Log form.

## Secure storage

All photos are stored securely with per-client folder isolation.

<Tip>Take before photos at the consultation for consistent comparison.</Tip>
