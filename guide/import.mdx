## Overview

The Import page lets you bring existing client data into ClinicTracker from a CSV file.

## How to import

1. Upload your CSV file
2. Map columns to ClinicTracker fields
3. Review duplicates (matched by email) and validation errors
4. Confirm import

<Tip>Clean your data before importing — remove blank rows and standardise email formats.</Tip>
