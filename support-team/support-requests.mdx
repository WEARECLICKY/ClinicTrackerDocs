## Overview

The Support Requests tab manages tickets submitted by clinic users.

## Responding to a request

1. Click a request to open details
2. Read the description
3. Add a response
4. Update status (Open, In Progress, Resolved, Closed)
5. Click **Send Response**

<Tip>Always update the ticket status when you've responded.</Tip>
